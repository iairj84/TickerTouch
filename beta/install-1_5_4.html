TickerTouch — Hardened Test Build

Version 1.5.4 — this is not the default firmware.

Skips calendar entries the feed has marked CANCELLED. A declined or removed occurrence is delivered as an ordinary event block at its original time, so it was being drawn as a meeting on a day it no longer exists — which is likely the phantom entry.

Because that is still a guess, this build also adds a calendar trace page at /cal (linked from the diagnostics page). It lists the last 24 event blocks exactly as the feed sent them — title, start, the date an edited occurrence came from, its status, and whether it repeats. If an entry still appears that should not, that page says why.

Keep your settings: this installer now asks whether to erase the device before flashing. Leave erase off — erasing wipes the WiFi credentials, city and league selection, and the board will come back up at its factory defaults (city "New York").
