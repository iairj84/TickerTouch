TickerTouch — Hardened Test Build

Version 1.5.0 — this is not the default firmware.

Adds a diagnostics page at /diag — the board can now tell you why it last reset, how much stack each task has left, the heap and PSRAM low-water marks, WiFi signal, photo storage, and how old each data feed's numbers are. Previously all of that only went to the serial port, which needs a cable and an IDE.

The photo page now shows a preview of every picture before it uploads, with the clock and ticker strip drawn over it exactly where the device puts them, so framing is decided by looking rather than by flashing and squinting.

The firmware also reports its own version number, and a GitHub Actions workflow now compiles every push so a sketch that does not build cannot reach the installer.

Keep your settings: this installer now asks whether to erase the device before flashing. Leave erase off — erasing wipes the WiFi credentials, city and league selection, and the board will come back up at its factory defaults (city "New York").
