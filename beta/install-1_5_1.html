TickerTouch — Hardened Test Build

Version 1.5.1 — this is not the default firmware.

Fixes two data bugs found on 1.5.0.

Basketball scores were missing. A game's two team records are over 11 KB of ESPN JSON, and the parser only ever had 8 KB to look at, so every NBA game was silently dropped while smaller leagues parsed fine. The parse window is now the whole buffer, and the scoreboard request asks for an unchunked body so a chunk header can never land inside a score.

Repeating calendar events did not appear. A daily or weekly meeting is shipped once with a rule, not once per day, so only its first occurrence was ever shown. Daily, weekly, monthly and yearly rules are now expanded across the seven visible days, including "every other week", weekday lists, end dates, occurrence counts and cancelled dates.

Also: the Web task stack went from 8 KB to 12 KB after the diagnostics page showed only 5.1 KB free, and the diagnostics page now prints the numeric code when it does not recognise the reset reason.

Keep your settings: this installer now asks whether to erase the device before flashing. Leave erase off — erasing wipes the WiFi credentials, city and league selection, and the board will come back up at its factory defaults (city "New York").
