TickerTouch 1.10.8 — A Second Source For Finance

Version 1.10.8 — beta. Stable is 1.10.6.

Finance now has two providers on two different hosts. 1.10.7 cut the stocks work from four requests per cycle to one, but that one request still went to Yahoo alone. When that host stopped answering this board, there was nothing else to fall back on, which is why Finance was the only tab that could go completely dark while four other feeds on four other hosts kept loading.

Spark remains the first choice: one request for the whole list, no crumb, a published percent change per symbol. If it returns nothing — a refused request, a connection that never completes, an empty body — the board now asks CNBC instead, in a single request, from a different host and a different edge. The two are never mixed: the second is used only when the first produced no prices at all. The serial log names which one answered.

What has been ruled out. The tickers are valid — SPY, NWPX (Northwest Pipe), COLM and CRMD each answer with a current price. The network is not throttled either: the same requests, from the same public IP, succeed from a desktop, including over HTTP/1.0, with no Accept header, and in bursts of thirty. So the fault is inside this board's own connection to that one host. This build is what makes that fault survivable rather than fatal, and the log is what will name it.

Keep your settings: the installer asks whether to erase the device. Leave erase off.

What to check
  • Finance populates within about thirty seconds of boot.
  • Serial shows [Stocks] SYM $price +x.xx% per symbol — with (cnbc) after the price if the second provider answered.
  • If both providers fail, send the [HTTP] lines: the status code (429, 401, -1) plus the two hostnames is enough to identify the cause.
