TickerTouch — Games No Longer Go Missing

Version 1.9.5 — beta. Stable is 1.9.4.

The sports count flickered between 6 and 5 with the feed unchanged. The scoreboard is parsed from a rolling 16 KB buffer. When the buffer passed three-quarters full, it silently kept only its last 8 KB — but the parser had already slid the current game's block to the front and was waiting for it to finish arriving. Losing the front of that block means one team instead of two, so the game was skipped. Whether that happened depended on where the network reads happened to land, which is why it came and went.

Compaction now only happens while looking for the next game. Once a block is being assembled, or its status is being read, nothing is discarded. A block that still cannot be completed is logged instead of vanishing quietly.

Keep your settings: the installer asks whether to erase the device. Leave erase off — erasing wipes WiFi, city, leagues, both calendar URLs and the icon choices.

What to check after installing
  • The sports count stops oscillating between fetches.
  • Serial shows each league's game count and no block skipped lines.
  • Settings → Sports → Fetch now agrees with the tab, repeatedly.
  • Other tabs are untouched by this change.

If a block skipped line does appear, it names the league and the buffer length, which says whether the block was truncated by the network or larger than the buffer.

Your browser does not support Web Serial — use Chrome or Edge on desktop. Web Serial needs HTTPS (this page is) and a direct connection.
