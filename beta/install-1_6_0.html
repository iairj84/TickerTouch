TickerTouch — Two Calendars

Version 1.6.0 — this is not the default firmware.

The calendar tab can now show two feeds at once — personal and work.

Events from the second calendar carry their own colour down the left edge of the row and their own icon on the right, so the two never read as one list. Leave the second URL blank and the calendar looks exactly like it does today.

The icon is chosen per calendar in settings (Home, Keyboard, Folder, Mail, Phone, Dot, or none).

Where both calendars contain the same event at the same time, it is shown once instead of twice. Two different things at the same time still both appear.

Keep your settings: this installer asks whether to erase the device before flashing. Leave erase off — erasing wipes the WiFi credentials, city and league selection, both calendar URLs, and the board will come back up at its factory defaults (city "New York").

What to check after installing
  • Settings shows two calendar URL fields, each with an icon picker.
  • With only the first URL filled in, the calendar tab looks unchanged.
  • With both filled in, rows show a colour bar and an icon.
  • An event that exists on both calendars appears once.

/cal now tags every block A (first calendar) or B (second), so a wrong entry can be traced to the feed it came from. /diag still shows feed health.

Your browser does not support Web Serial — use Chrome or Edge on desktop. Web Serial needs HTTPS (this page is) and a direct connection.
