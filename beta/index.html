Version 1.2.0 — this is not the default firmware.

Adds task-watchdog coverage around the HTTP reads, moves network setup off the 8 KB loop‑task onto a 40 KB main task, and defers two LVGL object deletions that ran inside their own event callbacks.

This image has never run on hardware. It compiles for the JC4827W543 (ESP32-S3, 4 MB flash, OPI PSRAM) and nothing more has been proven. Flashing replaces the current firmware; WiFi credentials in NVS are left alone.
