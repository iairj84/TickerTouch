TickerTouch — Feed Tests and Collapsible Settings

Version 1.9.0 — this is not the default firmware.

Fetch now. Each calendar URL, the stock tickers and the crypto list now have their own Fetch now button, with the result printed underneath: how many events came back from each calendar, the next event, the parsed prices, or a plain statement that the fetch failed. A mistyped or private calendar link used to fail silently until the next scheduled refresh, which looked identical to a working feed with nothing on today.

Collapsible sections. The settings page now shows section headings that open on tap, so the fields you came for are not buried under sports filters. Open sections are remembered between visits and survive a save.

Keep your settings: the installer asks whether to erase the device. Leave erase off — erasing wipes WiFi, city, leagues, both calendar URLs and the icon choices.

What to check after installing
  • Settings opens with the sections collapsed; tapping a heading opens it.
  • Calendar → Fetch now reports a count for each calendar and the next event.
  • Deliberately break calendar 2's URL, fetch, and confirm it says that feed parsed nothing.
  • Stocks → Fetch now lists the parsed prices.
  • Save the form, come back, and confirm the section you were editing is still open.

The fetch itself still runs on the device's data task, so a slow feed takes its time without freezing the page. The button waits up to 45 seconds and then says so.

Your browser does not support Web Serial — use Chrome or Edge on desktop. Web Serial needs HTTPS (this page is) and a direct connection.
