1.10.7 — Finance That Reloads

Version 1.10.7 — beta. Stable is 1.10.6.

Stocks made four TLS requests to Yahoo every 30 seconds — one per symbol, because the chart endpoint only takes one ticker at a time. Every other feed uses a different host, which is why Finance alone went dark while everything else kept loading. 1.10.7 asks for the whole symbol list in one request, retries against the other Yahoo edge host if the first refuses, and logs the outcome per symbol so a refusal shows the actual status code instead of an empty tab.

The tickers themselves are fine — SPY, NWPX, COLM and CRMD all answer normally. The problem was the request path, not the watchlist.

What to check: Finance fills in within about thirty seconds of boot, serial shows one [Stocks] SYM $price +x.xx% line per symbol and then [Stocks] done: 4, and /diag shows Finance with a recent age. Full notes on the installer page.

Your browser does not support Web Serial — use Chrome or Edge on desktop. Web Serial needs HTTPS (this page is) and a direct connection.

Keep your settings: the installer asks whether to erase the device. Leave erase off.
