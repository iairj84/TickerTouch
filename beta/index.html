TickerTouch — Hardened Test Build

Version 1.3.5 — this is not the default firmware.

Adds task-watchdog coverage around the HTTP reads, moves network setup off the 8 KB loop‑task onto a 40 KB main task, defers two LVGL object deletions that ran inside their own event callbacks, and stops the sports/calendar fetch from asking for 1970-01-01 before the clock syncs.

This image has never run on hardware. It compiles for the JC4827W543 (ESP32-S3, 4 MB flash, OPI PSRAM) and nothing more has been proven.

Keep your settings: this installer now asks whether to erase the device before flashing. Leave erase off — erasing wipes the WiFi credentials, city and league selection, and the board will come back up at its factory defaults (city "New York").
