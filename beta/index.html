1.10.8 — A Second Source For Finance

Version 1.10.8 — beta. Stable is 1.10.6.

Finance now has two providers on two different hosts. 1.10.7 cut stocks from four requests per cycle to one, but that request still went to Yahoo alone, so when that host stopped answering this board there was nothing to fall back on. Spark stays first; if it returns nothing, the board asks CNBC instead — one request, a different host, a different edge — and never mixes the two into one set of prices. The serial log says which provider answered.

The tickers are fine (SPY, NWPX, COLM, CRMD all answer) and so is the network: the same requests from the same public IP succeed from a desktop. The fault is in this board's own connection to that one host.

What to check: Finance fills in within about thirty seconds of boot, serial shows a [Stocks] SYM $price +x.xx% line per symbol (with (cnbc) if the second provider answered), and /diag shows Finance with a recent age. Full notes on the installer page.

Your browser does not support Web Serial — use Chrome or Edge on desktop. Web Serial needs HTTPS (this page is) and a direct connection.

Keep your settings: the installer asks whether to erase the device. Leave erase off.
