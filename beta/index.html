TickerTouch — A Finished Morning Is Not an Empty Day

Version 1.9.2 — beta. The default installer is 1.7.2.

The empty states now tell the truth. 1.9.1 started retiring events once they finished, which left the Home tab saying No events today and the Calendar tab saying No upcoming events after a busy morning. Both were wrong: the day had been full, it was just over.

With nothing left to show, they now say 2 earlier - nothing left, using the number of rows retired so far today. A calendar that genuinely has nothing on it still reads No events today.

Keep your settings: the installer asks whether to erase the device. Leave erase off — erasing wipes WiFi, city, leagues, both calendar URLs and the icon choices.

What to check after installing
  • After today's last event ends, Home shows N earlier - nothing left rather than "No events today".
  • The Calendar tab shows the same count instead of "No upcoming events".
  • A day with no events at all still reads No events today / No upcoming events.
  • Tomorrow's events still list normally, and the count only reflects today.

The count covers today only and restarts at each calendar fetch, so it cannot drift upward across a long uptime.
