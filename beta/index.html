TickerTouch — Today Stays Accounted For

Version 1.9.3 — beta. The default installer is 1.7.2.

The Calendar tab no longer skips today. 1.9.2 fixed the empty calendar, but that message only appeared when the whole week was empty. With tomorrow still holding events, the list opened straight on Tomorrow and read as though today had never had anything on it.

Today's place is now held by one muted line — 2 earlier - nothing left — sitting where the Today header would be. The finished events themselves still cost nothing: it is one line, not a list of rows you have to scroll past.

Keep your settings: the installer asks whether to erase the device. Leave erase off — erasing wipes WiFi, city, leagues, both calendar URLs and the icon choices.

What to check after installing
  • Once today's last event ends, the Calendar tab opens with N earlier - nothing left, then Tomorrow.
  • The Home tab agrees on the same number.
  • While events remain today, no such line appears and nothing else changes.
  • Tomorrow's rows still scroll normally under their header.

The line appears only when today has no rows left but the retired count is above zero, so a quiet day never gets one.

Your browser does not support Web Serial — use Chrome or Edge on desktop. Web Serial needs HTTPS (this page is) and a direct connection.
