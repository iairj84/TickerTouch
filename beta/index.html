TickerTouch — The Finished-Today Line Sits In The List

Version 1.9.4 — beta. The default installer is 1.7.2.

Cosmetic fix. In 1.9.3 the line above Tomorrow was a bare label, so it sat hard against the left edge with no band behind it and looked like text that had escaped the list. It now uses the same strip as the day headers — 20 px narrower than the panel, indented 8 px, 22 px tall, with the left rule — and reads Today - 2 earlier, nothing left, which is the heading it is replacing.

Keep your settings: the installer asks whether to erase the device. Leave erase off — erasing wipes WiFi, city, leagues, both calendar URLs and the icon choices.

What to check after installing
  • The "Today - N earlier" strip lines up with the "Tomorrow" header below it.
  • It is muted rather than accent-coloured, so it does not compete with a live day.
  • Everything else — pruning, fetch-now, collapsing — is unchanged.
Your browser does not support Web Serial — use Chrome or Edge on desktop. Web Serial needs HTTPS (this page is) and a direct connection.
