TickerTouch — Backup and Night Dimming

Version 1.8.0 — this is not the default firmware.

Backup. Settings can now be downloaded as a single JSON file and restored later. That removes the standing risk in every install page: erasing the device wipes the WiFi credentials, city, leagues, both calendar URLs and the icon choices, and until now there was no way back except retyping them.

Night brightness. A second, dimmer level for a window of the day — by default 22:00 to 07:00 — with its own level. The normal brightness slider is unchanged; the dim level simply takes over inside the window.

Keep your settings: this installer asks whether to erase the device before flashing. Leave erase off — or download a backup from the settings page afterwards and keep it somewhere private, since the file contains your secret calendar URLs.

What to check after installing
  • Settings now has a Night brightness section and a Backup section.
  • Download the file, then upload it back — it should report that settings were restored.
  • Set the night window to a minute or two in the future to watch the panel dim.
  • The calendar, stocks and sports sections should be exactly as they were.

Night dimming is evaluated on the device clock, so it follows the timezone the panel is using — check /diag if the window fires at the wrong hour. A window that runs past midnight is handled, which is the normal case.

Your browser does not support Web Serial — use Chrome or Edge on desktop. Web Serial needs HTTPS (this page is) and a direct connection.
